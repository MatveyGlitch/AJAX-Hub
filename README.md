# 🌐 AJAX Hub

**AJAX Hub** — учебное веб-приложение, созданное в рамках лабораторной работы №6 по дисциплине **«Web-программирование»**.

Проект объединяет AJAX-поиск, новостную страницу и расписание занятий. Данные загружаются асинхронно, без полной перезагрузки страниц.

---

## ✨ Возможности сайта

**Поиск по никнеймам**

- отправка POST-запросов к `ajax.php` через Fetch API;
- поиск по одному или нескольким словам;
- вывод результатов порциями по 10 записей с кнопкой «Показать ещё»;
- добавление новых результатов к уже загруженным;
- сортировка по алфавиту;
- сохранение результатов поиска в Cookies и выделение восстановленных записей.

**Новости**

- асинхронная загрузка публикаций из `ajax.php`;
- поиск по тексту и сортировка;
- постраничная навигация без перезагрузки;
- просмотр полного текста в модальном окне с отдельной AJAX-загрузкой;
- иллюстрации для публикаций;
- восстановление последнего поиска из Cookies.

**Расписание занятий**

- автоматическое определение текущего дня и верхней/нижней учебной недели;
- отображение даты и номера учебной недели;
- фильтры по предмету, курсу, группе, дню и типу недели;
- сохранение выбранных фильтров в Cookies с подсветкой восстановленных значений;
- раскрытие подробной информации о паре в аккордеоне;
- асинхронная загрузка расписания и времени звонков из JSON-файлов.

## 📄 Структура проекта

| Файл или каталог | Назначение |
|---|---|
| `index.html` | Поиск по никнеймам и подборка публикаций |
| `news.html` | Новостная страница |
| `schedule.html` | Расписание занятий |
| `ajax.php` | Обработка запросов и выдача JSON с никнеймами и новостями |
| `js/common.js` | Общие функции AJAX-запросов и работы с Cookies |
| `js/search.js` | Поиск, дозагрузка и сортировка результатов |
| `js/news.js` | Новости, пагинация, поиск и модальное окно |
| `js/schedule.js` | Учебные недели, фильтры и отображение занятий |
| `data/schedule.json` | Расписание верхней и нижней недель |
| `data/bells.json` | Время начала и окончания пар |
| `css/style.css` | Оформление и адаптивная вёрстка |
| `assets/` | Иллюстрации интерфейса и новостей |

Данные новостей и никнеймов используются как учебный пример. Расписание составлено для **3 курса, группы ИВТ-5 (Дизайн 1), 5 семестр**.

## 🛠️ Используемые технологии

- **HTML5 / CSS3** — разметка и адаптивное оформление страниц;
- **JavaScript / Fetch API** — асинхронные POST-запросы и обновление интерфейса;
- **PHP 8** — обработка запросов в `ajax.php`;
- **JSON** — формат обмена данными и хранения расписания;
- **Cookies** — восстановление результатов поиска и настроек фильтров;
- **XAMPP / Apache** — локальный запуск проекта;
- **Git / GitHub** — контроль версий и хранение исходного кода.

## 🎨 Особенности интерфейса

Сайт оформлен в едином стиле **Editorial / Aurora Glass**: светлая лавандовая палитра, полупрозрачные элементы, карточки публикаций и горизонтальная навигация. Вёрстка адаптируется к ширине экрана с помощью CSS Grid, Flexbox и медиазапросов.

## 🚀 Локальный запуск

1. Скачать или клонировать репозиторий.
2. Установить XAMPP с поддержкой PHP 8.
3. Разместить проект в `C:\xampp\htdocs\lab6-ajax` либо создать ссылку на папку проекта в `htdocs`.
4. Запустить **Apache** через XAMPP Control Panel.
5. Открыть в браузере [AJAX Hub](http://localhost/lab6-ajax/index.html).

Другие страницы: [Новости](http://localhost/lab6-ajax/news.html) · [Расписание](http://localhost/lab6-ajax/schedule.html).

PHP и AJAX-запросы требуют веб-сервера: открытие HTML-файлов напрямую через `file://` не подходит. **MySQL не требуется.**
